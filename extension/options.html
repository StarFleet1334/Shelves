Shelves

Group your GitHub repositories by topic.

Your shelves

One topic per shelf, in the order they should appear. A repo goes on the first shelf whose topic it carries. Leave this empty to group automatically by whatever topics you already use.

Private repositories

By default, topics for private repos are read from your own repo pages using the session you are already signed in with — slower on first load, then cached. A token replaces that with a single API call.

How to make a safe token
  1. Open github.com/settings/tokens?type=beta → Generate new token
  2. Repository access: All repositories
  3. Permissions → Repository permissions → Metadata: Read-only
  4. Leave every other permission at No access

Metadata-read-only is the weakest token GitHub can issue: it cannot read a line of your code and cannot write anything at all. It is kept in this browser's local extension storage — never in synced storage, never sent anywhere but api.github.com.

Behaviour

Off by default, and deliberately so. Everything else here spends a request on a page you opened to see the result; this one refreshes a few repo pages while you are elsewhere on github.com, so that a week-old cache is never the fifteen seconds you wait for. It only refreshes repos it has already seen, one at a time, at most 6 per page you visit, never on your Repositories tab, never in a background tab, and it stops on the first refusal.

Shelves never writes to your GitHub account. It reads topics and rearranges the page in your browser — uninstalling it leaves GitHub exactly as it was.
